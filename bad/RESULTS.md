# Результаты

## Протокол (общий для обеих категорий)

Категория → `drop_duplicates(["name","description"])` **до** сплита →
`StratifiedGroupKFold(5, shuffle, seed=42)`, `y=label`, `groups=md5(description)`.
Утечка групп = 0, проверено.

Метрика — `f1_score(y_true, y_pred)` (binary, `pos_label=1`), как в коде организаторов.
* **F1\*** — порог подобран на всём OOF (так меряют обычно, но это оптимистично);
* **F1 nested** — порог подбирается на остальных фолдах и применяется к текущему.
  Все выводы ниже сделаны по nested.

## Ансамбль в сабмите

```
rosb-ev + rmb-ev-s1337 + rub-ev-r200   (простое среднее вероятностей, порог 0.60)
F1 nested = 0.9540    по фолдам 0.9508 0.9525 0.9540 0.9564 0.9563  (std 0.0026)
```

Цель была 0.943 → **+0.011**, и каждый отдельный фолд выше цели.
Top-20 составов лежат в коридоре 0.9516–0.9542, то есть выбор не артефакт перебора.

Стэкинг сложнее среднего (LogReg на логитах, HistGBM, подбор неотрицательных весов)
на 5565 строках хуже: 0.9424–0.9441. Пофолдовые и посегментные пороги тоже хуже
глобального (0.9394 / 0.9436 против 0.9462).

## Где ошибается

411 ошибок (206 FP / 205 FN) у более раннего варианта ансамбля:

| сегмент | n | доля 1 | ошибок | error rate |
|---|---|---|---|---|
| маркера БАД в тексте нет | 671 | 0.177 | 87 | 0.130 |
| есть POS, нет NEG | 4612 | 0.817 | 313 | 0.068 |
| есть POS и NEG | 282 | 0.202 | 11 | 0.039 |

21 % ошибок — сегмент без текстового маркера (доказательство на упаковке).

Проба Qwen3-VL-2B на 300 товарах: AUC 0.75, сигнал есть.
Ещё 21 ошибка — строки из групп с противоречивой разметкой, неустранимый шум.

# ЛВЖ — 3951 строка, доля 1 = 0.036

## Разметка DeepSeek

`deepseek/deepseek-v3.2` (веса MIT — дистилляция не нарушает запрет на обучение
на объяснениях закрытой проприетарной модели). Схема из 4 полей, вердикт передаётся
модели как GOLD, её задача — обосновать, а не угадать.

* принято валидатором **3875 / 3951 (98.1 %)**, стоимость **$1.44**;
* с первой попытки 3344, остальные — ретраями с текстом претензий валидатора;
* сработавшие правила: №4 «нет источника/горючего» — 2154, №5 «пустая ёмкость» — 802,
  №8 «горючее не в комплекте» — 302, позитивные №1–3 — 207.
  Правила 1 и 2 смешанные по классам (35/55 и 48/34) — это и есть трудные карточки.

## Модель

DoRA поверх Qwen3-1.7B, лосс

```
L = w_y · CE_2tok(Да, Нет) + λ · (1/T) Σ CE_vocab(ОБЪЕКТ+ФАКТ+ПРАВИЛО)
```

`w_y = 6` для позитива, CE_2tok — софтмакс только по двум токенам вердикта в позиции
сразу после «ЛВЖ:», reasoning-лосс усреднён по числу токенов, EOS не входит.
Проверено юнит-тестом на совпадение с эталонной формулировкой.

Инференс `--infer cot`: модель сама пишет разбор, потом читается двухтокенный софтмакс.

Временная заглушка в архиве (TF-IDF word+char → LogReg): OOF F1 nested **0.699**,
её заменит DoRA-модель.

## Инженерные находки

* reasoning-лосс нельзя считать по всем позициям: full-vocab CE по B·T·|V| — это
  fp32-тензор на 620 млн элементов каждый шаг. Собираем только позиции рассуждения.
* DoRA держит живой полную копию каждой адаптируемой матрицы (нужна ‖W+BA‖).
  На MLP это +12 ГБ: 36 ГБ против 24 ГБ. Отсюда attention-only по умолчанию.
* бакетизация по длине: средняя длина 563 при максимуме 1024, без неё ~40 % батча — паддинг.
