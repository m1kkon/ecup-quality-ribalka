# Данные

Исходный train уже включён в репозиторий как `../../data/data.csv` и используется
всеми командами по умолчанию. Другой файл можно передать через `--data`.

Обязательные столбцы: `id`, `name`, `description`, `category`, `label`.
Код сам оставляет `category == "БАД"`, заполняет пустые тексты и удаляет точные
дубликаты `name + description` до CV.
